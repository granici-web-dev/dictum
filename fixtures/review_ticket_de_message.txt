1. Проверять форму входа до отправки
Проверять поля формы входа в браузере, пока запрос не ушёл на сервер. API не меняется: оно принадлежит Backend-Team.

Ограничения:
• проверка в браузере, до запроса к серверу
  «Die Felder des Login-Formulars sollen im Browser geprüft werden, bevor eine Anfrage an den Server geht.»
Критерии приёмки:
• пустое обязательное поле показывает ошибку под полем
  «Ein leeres Pflichtfeld zeigt eine Fehlermeldung unter dem Feld.»
• неверный адрес e-mail показывает ошибку под полем
  «Eine ungültige E-Mail-Adresse zeigt eine Fehlermeldung unter dem Feld.»
• пока поле неверно, запрос к API не уходит
  «Solange ein Feld ungültig ist, geht keine Anfrage an die API.»
Не надо:
• менять API: оно принадлежит Backend-Team
  «Die API bleibt unverändert, sie gehört dem Backend-Team.»
