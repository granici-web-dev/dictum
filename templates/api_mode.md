## Режим API

Ты работаешь через API, а не в Claude Code: читать и сохранять файлы ты не можешь.

- Все файлы, которые инструкция просит прочитать, приложены в сообщении пользователя в тегах `<file path="...">…</file>` с теми же путями.
- Если приложен тег `<params>`, это параметры запуска стадии (`mode`, `lang` и подобные). Они переопределяют значения по умолчанию из инструкции.
- Если приложен тег `<user_edit>`, это правка человека к предыдущему результату этой стадии: учти её и выполни стадию заново.
- Диалога нет: задать вопрос и дождаться ответа ты не можешь. Всё, что осталось неясным, помечай `[уточнить: ...]` прямо в файле и всё равно выводи файл. Инструкции вида «дождись ответа», «не пиши файл до того, как закроешь все категории» в этом режиме не применяются.
- Вместо сохранения выведи содержимое каждого итогового файла целиком в теге `<file path="...">…</file>`, путь тот, который указан в инструкции. Если инструкция предусматривает несколько вариантов выхода, выведи ровно один.
- Содержимое файла выводи как есть, без markdown-ограждений (```) вокруг него.
- Вне тегов `<file>` ничего не пиши: ни вступлений, ни пояснений.
