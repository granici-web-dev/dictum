Скрипты, которые запускают руками. Ни один не вызывается из пайплайна.

- `clear_board.py` — убрать карточки демо-доски в архив перед прогоном репетиции.
  `make clean-board` уберёт всё, `make clean-board RUN=<run_id>` — только один прогон.
  Спрашивает подтверждение; архив обратим, доска после него чистая.

Артефакты прогонов на диске убирает `make clean-runs` — тоже руками и тоже с вопросом.
Автоматически `runs/` не трогает никто: артефакт упавшего прогона иногда единственное,
по чему видно, что случилось.
