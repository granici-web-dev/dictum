# Dictum

Личный инструмент одного человека: созвон с тимлидом, руководителем проекта или проект-менеджером, записанный на диктофон с согласия участников, прогоняется через приложение, чтобы точно понять, что поручено. Вход: запись с диктофона, голосовое или текст в Telegram, в том числе текст тикета Jira. Результат: разбор встречи, где у каждого поручения есть суть на русском, кто поручил, срок, «не надо» и что переспросить, а сказанное стоит в оригинале с переводом рядом; следом приходит полная расшифровка. Под каждым поручением две кнопки: «Разложить на шаги» и «Шаги без ресёрча». Обе сначала собирают вопросы для тимлида на языке встречи, с переводом и пояснением, зачем спрашивать: нужные вы отбираете и отправляете сами, бот тимлиду не пишет ничего. Пока ответа нет, поручение ждёт и чат не занимает: можно прислать новую запись или взять другое поручение. Ответ пришлите ответом (reply) на сообщение с вопросами, можно частично, а идти без него — кнопка «Продолжить без ответов». Дальше ресёрч решений в вебе, который «Шаги без ресёрча» пропускает, и шаги на воротах: короткое «ок» текстом карточку не публикует, утверждение — это кнопка «Дальше». Вопросы, оставшиеся без ответа, доезжают до карточки открытыми. Кнопка «Проработать как идею» под оглавлением ведёт всю запись путём своей идеи: вопросы брифа, бриф, PRD, задачи и карточки.

Старт: `cp .env.example .env`, заполнить, `make up`, `uv sync`, `make db`, `make test`. Досок в Trello две: `TRELLO_BOARD_ID` для карточек поручений и `TRELLO_IDEA_BOARD_ID` для пути идеи; без второй бот работает, а кнопка идеи отказывает сразу.
Для голосовых и записей нужны ffmpeg и ffprobe, ставятся вместе: `brew install ffmpeg` на macOS, `apt install ffmpeg` на Debian.
Локальный прогон без бота кончается разбором в `outputs/review.md`: `make run-text TEXT="Kannst du bis Freitag das Login-Formular prüfen? Bitte die API nicht anfassen."`. Шаги поручения N из этого разбора: `make run-text ARGS="--task N"` идёт вопросами для тимлида и ресёрчем решений и пишет `outputs/steps.md`; ответа он не ждёт — вопросы ложатся в `outputs/clarify.json`, а шаги идут без них. `ARGS="--task N --no-research"` ведёт тот же путь без единого платного поиска. Повторить по лежащим артефактам: `ARGS="--from approach"` — ресёрч, `ARGS="--from steps --answers файл"` — шаги с ответом тимлида из файла, как его прислали. На доску шаги кладёт `python -m app.publish outputs/steps.json` одной карточкой в список `Assignments`. Путь до бэклога своей идеи для отладки стадий: `make run-text ARGS="--from intake"` по лежащему `inputs/transcript.md`, на доску идей его кладёт `python -m app.publish outputs/issues.json`.

Архитектура — `SPEC.md`. Что делать сейчас — `PLAN.md`. Правила — `CLAUDE.md`.
