# idea2backlog

Идея → бриф → PRD → issues → Trello. Вход: голосовое в Telegram, аудиофайл или текст.

Старт: `cp .env.example .env`, заполнить, `make up`, `uv sync`, `make test`.
Локальный прогон без бота: `make run-text TEXT="Хочу, чтобы бот напоминал о дедлайнах"`.

Архитектура — `SPEC.md`. Что делать сейчас — `PLAN.md`. Правила — `CLAUDE.md`.
