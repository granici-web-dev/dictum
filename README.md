# idea2backlog

Личный инструмент одного человека: созвон с тимлидом, руководителем проекта или проект-менеджером, записанный на диктофон с согласия участников, прогоняется через приложение, чтобы точно понять, что поручено. Вход: запись с диктофона, голосовое или текст в Telegram. Результат: разбор встречи, где у каждого поручения есть суть на русском, кто поручил, срок, «не надо» и что переспросить, а сказанное стоит в оригинале с переводом рядом; следом приходит полная расшифровка. Кнопка под поручением раскладывает его на шаги и кладёт карточкой в Trello, а кнопка «Проработать как идею» под оглавлением ведёт всю запись путём своей идеи: вопросы брифа, бриф, PRD, задачи и карточки.

Старт: `cp .env.example .env`, заполнить, `make up`, `uv sync`, `make db`, `make test`. Досок в Trello две: `TRELLO_BOARD_ID` для карточек поручений и `TRELLO_IDEA_BOARD_ID` для пути идеи; без второй бот работает, а кнопка идеи отказывает сразу.
Для голосовых и записей нужны ffmpeg и ffprobe, ставятся вместе: `brew install ffmpeg` на macOS, `apt install ffmpeg` на Debian.
Локальный прогон без бота кончается разбором в `outputs/review.md`: `make run-text TEXT="Kannst du bis Freitag das Login-Formular prüfen? Bitte die API nicht anfassen."`. Шаги поручения N из этого разбора: `make run-text ARGS="--task N"` пишет `outputs/steps.md`, а на доску их кладёт `python -m app.publish outputs/steps.json` одной карточкой в список `Assignments`. Путь до бэклога своей идеи для отладки стадий: `make run-text ARGS="--from intake"` по лежащему `inputs/transcript.md`, на доску идей его кладёт `python -m app.publish outputs/issues.json`.

Архитектура — `SPEC.md`. Что делать сейчас — `PLAN.md`. Правила — `CLAUDE.md`.
