# idea2backlog

Личный инструмент одного человека: созвон с тимлидом, руководителем проекта или проект-менеджером, записанный на диктофон с согласия участников, прогоняется через приложение, чтобы точно понять, что поручено. Вход: запись с диктофона, голосовое или текст в Telegram. Конвейер сегодня прежний: идея, бриф, ресёрч, PRD, декомпозиция, карточки в Trello. Подходит ли он новой цели, решает строка "Пересмотр под новую цель" в PLAN.md.

Старт: `cp .env.example .env`, заполнить, `make up`, `uv sync`, `make db`, `make test`.
Для голосовых и записей нужны ffmpeg и ffprobe, ставятся вместе: `brew install ffmpeg` на macOS, `apt install ffmpeg` на Debian.
Локальный прогон без бота: `make run-text TEXT="Хочу, чтобы бот напоминал о дедлайнах"`.

Архитектура — `SPEC.md`. Что делать сейчас — `PLAN.md`. Правила — `CLAUDE.md`.
