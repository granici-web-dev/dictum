# idea2backlog

Личный инструмент одного человека: созвон с тимлидом, руководителем проекта или проект-менеджером, записанный на диктофон с согласия участников, прогоняется через приложение, чтобы точно понять, что поручено. Вход: запись с диктофона, голосовое или текст в Telegram. Результат: разбор встречи, где у каждого поручения есть суть на русском, кто поручил, срок, «не надо» и что переспросить, а сказанное стоит в оригинале с переводом рядом; следом приходит полная расшифровка. Путь от поручения до карточек в Trello вернётся кнопкой под поручением (фаза 2 P3-08).

Старт: `cp .env.example .env`, заполнить, `make up`, `uv sync`, `make db`, `make test`.
Для голосовых и записей нужны ffmpeg и ffprobe, ставятся вместе: `brew install ffmpeg` на macOS, `apt install ffmpeg` на Debian.
Локальный прогон без бота кончается разбором в `outputs/review.md`: `make run-text TEXT="Kannst du bis Freitag das Login-Formular prüfen? Bitte die API nicht anfassen."`. Путь до бэклога для отладки стадий: `make run-text ARGS="--from intake"` по лежащему `inputs/transcript.md`.

Архитектура — `SPEC.md`. Что делать сейчас — `PLAN.md`. Правила — `CLAUDE.md`.
